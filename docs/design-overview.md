# 设计概览：知识卡片闯关游戏（game-demo）

> 给 2 年级小朋友的知识卡片闯关游戏。兴趣驱动：🚗 汽车（德国汽车历史）· 🏯 中国历史 · 🧱 我的世界。
> 本文档是设计的入口；每个决策的完整论证见 [ADR 系列](./adr/)，术语见 [词汇表](./glossary.md)。

## 一句话定位

**网页上即开即玩、孩子独立可玩、家长放心的知识卡片闯关游戏**——答题闯关赢星星，星星解锁知识卡片，卡片填满三大兴趣世界的图鉴。

## 决策树摘要（全部经用户确认）

```
平台形态 ──► 网页游戏（纯静态，可托管 GitHub Pages/Vercel）
使用场景 ──► 孩子独立玩为主（极简 UI + 大字 + TTS 朗读）
核心玩法 ──► 答题闯关 + 卡片收集双循环
主题组织 ──► 三个独立主题世界（各自关卡树 + 图鉴）
关卡结构 ──► 5 题/关，答对 3 题过关，1-3 星
关卡树 ────► 每主题对称 10 关（8 普通+2 复习），子主题分组，杀戮尖塔式爬塔图
错题复习 ──► 错题池 + 复习关固定在第 4、8 位；池空变宝藏关
题型 ─────► 图片四选一为主 + 少量判断题，全程点按
知识扩展 ──► 每题图文学习页（标题+正文+插图+来源+https白名单外链），答题后/图鉴双入口
小游戏 ────► 每主题 1 个（组装/拼图/挖矿），主题通关解锁，小游戏厅选玩；全通解锁彩蛋小游戏「摩托大乱斗」（ADR-0015）
题库 ─────► 内置人工审核题（JSON 格式，每主题 42 题，4 档难度）+ 家长自定义题 JSON 导入
难度系统 ──► 4 档年级制（🌱启蒙~👑高级），主界面全局选择，出题按难度+最近回退
家长控制 ──► 本地存档、家长专区、每日时长上限、15 分钟休息提醒、零广告零内购
视觉 ─────► 明亮卡通风 + MC 主题原创像素图（零版权风险）
声音 ─────► Web Audio 合成音效 + 浏览器 TTS 朗读 + 一键静音
技术栈 ───► Vite + React + TypeScript + TailwindCSS + Framer Motion + localStorage
交付 ─────► 本地开发 + 静态构建部署
MVP ──────► 三主题各 2-3 关 + 核心双循环 + 简单家长专区
```

## 架构草图（MVP）

```
┌──────────────────────────────────────────────┐
│  React 单页应用（Vite + TS + Tailwind）         │
│                                               │
│  主界面 ──► 主题世界 ×3                         │
│              ├─ 爬塔关卡树（10 节点）           │
│              │   普通关 / 复习关 / 宝藏关 + 奖牌终点 │
│              ├─ 答题页（四选一/判断 + TTS）      │
│              ├─ 星级结算 + 庆祝 + 卡片逐张翻开   │
│              └─ 卡片图鉴（35 题卡 + 奖牌卡）     │
│                                               │
│  家长专区（谜题解锁）                            │
│     ├─ 每日时长 / 休息提醒 / 静音 / 清档         │
│     └─ 自定义题 JSON 导入                       │
│                                               │
│  ┌──────── 数据层 ────────┐                    │
│  │ 题库 JSON（内置+导入）   │                    │
│  │ localStorage 存档       │                    │
│  │ 错题池 / 图鉴 / 星星     │                    │
│  └────────────────────────┘                    │
│  音效/音乐：Web Audio 合成；朗读：SpeechSynthesis │
└──────────────────────────────────────────────┘
```

## 关键文件/模块规划

| 模块 | 职责 |
|---|---|
| `src/data/` | 内置题库 JSON（按主题）、家长导入格式 |
| `src/store/` | localStorage 存档模型（星星/进度/图鉴/错题池/设置） |
| `src/game/` | 关卡树（爬塔图数据）、关卡生成、出题、错题池、复习关/宝藏关、自由挑战 |
| `src/ui/` | 主界面、答题页、图鉴、家长专区、庆祝动画 |
| `src/audio/` | Web Audio 合成音效 + TTS 封装 |

## MVP 验收清单

- [ ] 三主题全部 10 关可完整通关（7 普通 + 2 复习 + 大满贯），星级与星星正确结算
- [ ] 爬塔图渲染完整 10 节点，未解锁暗锁、当前关玩家小人、通关亮星
- [ ] 答错进入错题池，复习关可抽出并移出；错题池空时变宝藏关
- [ ] 图鉴随过关解锁卡片，解锁动画可见
- [ ] 题目/选项 TTS 朗读可用；无 TTS 环境静默降级
- [ ] 家长专区可设时长上限，到点锁定；休息提醒 15 分钟触发
- [ ] `npm run dev` 一键运行，`npm run build` 产物可静态部署
- [ ] 历史题史实复核通过；全部题目符合 2 年级可读性规范

## 后续迭代方向（明确不做进 MVP）

家长题导入 UI → 成就徽章 → 排行榜 → PWA 离线 → 云同步 → MC 搭世界玩法。
