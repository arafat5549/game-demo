# 家长自定义题目格式（JSON）

> 家长可以在「家长专区 → 自定义题目」导入自己的知识题，与内置题库一同游玩（ADR-0008）。
> 本格式与内置题库完全一致——你可以直接拿内置题库当模板改。内置题库按难度分文件夹存放：
> `src/data/questions/<难度>/<主题>.json`（难度：`starter` 启蒙 / `beginner` 初级 / `intermediate` 中级 / `advanced` 高级）。

## 导入方式

1. 主界面点 🔒 进入家长专区，通过星星谜题解锁；
2. 在「自定义题目」区域选择 **JSON 文件**（`.json`），或把 JSON 文本**粘贴**到输入框；
3. 点「导入」，校验通过后显示成功数量；导入的题目会进入对应主题世界的**宝藏关**随机池和**复习关**补位池。

## JSON 结构

一个**数组**，每个元素是一道题：

```json
[
  {
    "id": "custom-history-1",
    "theme": "history",
    "subTheme": "qinshihuang",
    "difficulty": "beginner",
    "type": "choice",
    "prompt": "长城有多长？",
    "options": ["两万多公里", "一百米", "一千米", "一万米"],
    "answer": 0,
    "fact": "长城全长超过两万公里，所以叫“万里长城”。",
    "cardName": "长城长度",
    "cardEmoji": "🏯",
    "expansion": {
      "title": "长城到底多长",
      "body": "长城东起山海关，西到嘉峪关，全部连起来超过两万公里，能绕地球半圈。",
      "source": "来源：百度百科·万里长城",
      "links": [
        { "label": "百度百科：万里长城", "url": "https://baike.baidu.com/item/万里长城" }
      ]
    }
  }
]
```

## 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一标识，建议以 `custom-` 开头；与已有题目冲突会导入失败 |
| `theme` | ✅ | 归入的主题世界：`car`（汽车博物馆）/ `history`（历史之旅）/ `minecraft`（MC 方块世界） |
| `subTheme` | ✅ | 子主题分类（仅用于归类，自定义题不进入普通关） |
| `difficulty` | ✅ | `beginner`（初级）/ `intermediate`（中级） |
| `type` | ✅ | `choice`（四选一）/ `judge`（判断题） |
| `prompt` | ✅ | 题目文字（短句、口语化、孩子能听懂） |
| `options` | ✅ | 选项数组：四选一为 4 个；判断题为 `["对","错"]` |
| `answer` | ✅ | 正确选项下标，从 0 开始（判断题：0=对，1=错） |
| `fact` | ✅ | 一句话知识小故事（答错时朗读） |
| `cardName` | ✅ | 知识卡片名（显示在图鉴里） |
| `cardEmoji` | ✅ | 卡片图标（一个 emoji） |
| `expansion` | ⬜ | 知识扩展（见下）；不填则答题后不出现"了解更多"按钮 |

### expansion 字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `title` | ✅ | 扩展页大字标题 |
| `body` | ✅ | 正文 2-4 句（50-80 字，可朗读） |
| `source` | ✅ | 来源标注（如"来源：百度百科·××"） |
| `image` | ⬜ | 预留插图地址，暂不生效 |
| `links` | ⬜ | 外链数组；**仅允许 https**，非 https 会导入失败 |

## 校验规则（导入时自动检查）

1. 必须是 JSON 数组，且**每主题不超过 200 题**；
2. 每题必填字段齐全，`answer` 必须在 `options` 下标范围内；
3. `options` 数量：`choice` 必须 4 个，`judge` 必须 2 个且为 `["对","错"]`；
4. `id` 不得与内置题库或其他已导入题目重复；
5. 所有 `links` 必须为 `https://` 开头；
6. 任一题不合规 → 整批拒绝导入，并提示第一条错误原因。

## 写作建议（2 年级可读性规范）

- 题目和选项用**短句**，单句不超过 20 字；
- 答案唯一、无歧义；
- 历史题请核对来源，`source` 里写明出处；
- 每题配一句鼓励式 `fact`，答错时孩子会听到它。
