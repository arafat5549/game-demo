# ADR-0002: 技术栈——Vite + React + TypeScript 纯前端

- 状态：已接受
- 日期：2026-08-03

## 背景

知识卡片闯关是 UI 密集型交互（答题页、图鉴、设置），不是强动画的实时游戏；同时需要 MC 主题的像素风表现。候选：Web 框架、Phaser 游戏引擎、Rust/WASM、前后端分离。

## 决策

| 层 | 选型 | 用途 |
|---|---|---|
| 构建 | Vite | 开发服务器 + 静态构建 |
| 语言 | TypeScript | 全量类型安全，题库与存档模型受益最大 |
| UI | React 18 + TailwindCSS | 答题页、图鉴、家长专区 |
| 动画 | Framer Motion | 过关庆祝、卡片解锁、连击特效 |
| 音效/音乐 | Web Audio API 合成 | 零素材零版权（见 ADR-0010） |
| 朗读 | 浏览器 SpeechSynthesis API（TTS） | 题目/选项朗读，中文语音 |
| 存档 | localStorage | 进度、星星、图鉴、错题池、家长设置 |
| 题库 | JSON 文件（内置）+ 家长导入 JSON | 内容与代码分离 |

## 后果

- 优点：UI 开发效率最高；无后端、无数据库、无部署运维；题库/存档模型可用 TS 类型严格约束。
- 代价：复杂粒子/物理效果不如游戏引擎；localStorage 容量有限（题库本身静态打包，不占存档空间）。
- 明确不采用：Phaser（儿童 UI 密集场景开发效率低）、Rust/WASM（迭代慢）、前后端分离（demo 阶段无必要，见 ADR-0011）。
