# ADR-0009: 家长控制与隐私——本地存档、时长限制、零商业元素

- 状态：已接受
- 日期：2026-08-03

## 背景

孩子独立玩 + 网页形态，家长最关心护眼、防沉迷、隐私与内容安全。

## 决策

1. **本地存档、零账号**：进度/星星/图鉴/错题池/设置全部存 localStorage（与 ADR-0001 的纯静态一致），无任何云端数据，无隐私合规负担。
2. **家长专区**：由简单谜题（如"点击第 3 颗星星"）解锁，防止孩子自行修改设置。提供：
   - 每日游玩时长上限（到点温和提示并锁定，次日重置）；
   - 每 15 分钟休息提醒（护眼）；
   - 家长导入题目入口（见 ADR-0008）；
   - 一键静音、清除存档。
3. **零商业元素**：无广告、无内购、无埋点。
4. **外链策略**（2026-08-03 由 ADR-0013 修订）：知识扩展页中的外链采用**白名单制**——仅 https、内置题库链接人工审核、渲染加 `rel="noopener noreferrer"`、家长导入题链接强制 https 校验。原"零外链"条款废止。

## 后果

- 优点：家长零顾虑、无需账号体系；本地存档天然保护隐私。
- 代价：跨设备不共享进度（demo 阶段可接受，列为未来方向）；家长专区谜题解锁是"防君子不防黑客"，对本场景足够。
