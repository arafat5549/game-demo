# ADR-0006: 关卡结构与错题复习——短关、宽松过关、错题池

- 状态：已接受
- 日期：2026-08-03

## 背景

2 年级孩子注意力约 10-15 分钟；失败惩罚过重会挫败，过轻则无闯关感。教育目标要求"答错后真正学会"。

## 决策

1. **每关 5 题**，答对 **3 题即过关**（宽松容错，保护成就感）。
2. **星级**：全对 3 星、对 4 题 2 星、对 3 题 1 星；星数作为解锁后续关卡/卡片的门槛（与 ADR-0004 的星星货币一致）。
3. **错题池 + 定期复习关**：答错的题自动进入该主题的错题池；关卡树中每过 3 个普通关出现 1 个**复习关**（从错题池抽 5 题，答对后移出错题池）。
4. 题目难度分**初级 / 中级**两档，随关卡树递进；每主题 MVP 关卡树见 ADR-0011。

## 后果

- 优点：关卡短（约 2-3 分钟一关），符合注意力时长；过关门槛低、重试无惩罚；错题复习闭环保证教育效果且孩子可感知。
- 代价：需要错题池数据结构与复习关生成逻辑；复习关插在关卡树中需要可视化标识。
- 明确不采用：10 题/关严格考试制（超耐心上限）、连续答对制（挫败感强）、无感知的间隔重复算法（孩子与家长都难感知进度）。
