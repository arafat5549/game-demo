# ADR-0001: 平台与交付形态——纯前端网页游戏

- 状态：已接受
- 日期：2026-08-03

## 背景

目标用户是 2 年级（7-8 岁）小朋友，产品形态未定。候选：网页游戏、手机/平板 App、微信小程序、桌面程序。

## 决策

1. 游戏形态为**网页游戏**：浏览器打开即玩，零安装。
2. 交付形态为**纯静态站点**：本地 `npm run dev` 开发，`npm run build` 产物可部署到 GitHub Pages / Vercel 等免费静态托管，发链接即玩，便于分享给家长和孩子。
3. 不做后端服务（见 ADR-0002）。

## 后果

- 优点：无需应用商店审核与签名；平板/电脑/手机均可玩；演示与分享成本为零；Web 技术栈迭代最快。
- 代价：无法离线游玩（后续可用 PWA 缓解）；受浏览器安全限制，存档仅限本地（与 ADR-0009 的本地存档决策一致）。
- 风险：儿童浏览器环境（如 iPad Safari）的 TTS 与音频兼容性需在 MVP 中实测。
