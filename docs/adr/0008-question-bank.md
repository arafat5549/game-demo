# ADR-0008: 题库策略——内置人工题库 + 家长 JSON 导入

- 状态：已接受
- 日期：2026-08-03

## 背景

内容型产品最重的部分是题库；历史题必须史实准确，儿童题必须表述适龄。需要质量可控且可扩展。

## 决策

1. **内置人工审核题库**：每个主题约 40 题，分**初级 / 中级**两档（对应 ADR-0006 的难度递进）；全部题目经人工编写与审核，特别对历史题做史实核对。
2. **每题 = 一张知识卡片**（与 ADR-0004 一一对应），卡片含：题目、选项、正确答案、配图、一句话知识小故事（朗读文本）。
3. **家长自定义题**：支持家长导入 JSON 文件（格式文档：`docs/custom-question-format.md`，与内置题库同构）。导入题进入独立的"家长题区"，出现在**宝藏关**随机池与**复习关**补位池（不进普通关，不改变关卡树）。2026-08-03 已实现：文件导入/粘贴、逐题校验（必填字段、answer 范围、选项数、id 冲突、https 白名单）、题目列表管理与删除。
4. **题库编写规范**（约束 ADR-0003 的可朗读性）：
   - 短句、口语化、单句不超过 20 字；
   - 每题选项 4 个，正确答案唯一；
   - 历史题注明史实来源依据，由人工复核。

## 后果

- 优点：质量可控、史实有保障；题库 JSON 与代码分离，内容可独立迭代；家长可注入家庭定制内容。
- 代价：40 题 × 3 主题的编写与配图是主要内容成本；家长导入需做 JSON 校验与安全解析（防脚本注入，纯前端本地解析，不执行导入内容）。
