# ADR-0017: 知识点级卡片体系——图鉴与题目难度解耦

- 状态：已接受
- 日期：2026-08-03
- 关联：ADR-0012（卡片收集）、ADR-0008（题库策略）、ADR-0013（知识扩展）、ADR-0016（难度系统）

## 背景

难度系统（ADR-0016）将题库扩展为 4 档年级制后（每主题 71 题），原"卡片与题目一一对应"的机制（ADR-0012）出现三处断裂：

1. **图鉴膨胀**：每主题 71 题 → 71 张题卡（原设计 35 张）；
2. **重复卡片**：同知识点跨难度多题并存，实测 11 个卡名重复出现（如"三巨头"在 beginner 与 advanced 各一张）；且部分跨难度同知识点卡名不一致（advanced"奔驰的诞生" vs beginner"汽车之父"），无法靠卡名自动合并；
3. **收集语义混乱**：同一知识点 4 档难度 = 4 张卡，孩子切难度后重复收集同一知识。

## 决策

### 1. 卡片粒度：知识点级（核心）

- **卡片与知识点对应，不再与题目一一对应**；同知识点跨难度共享一张卡；
- 题库每题新增 `knowledge` 字段（如 `inventor-benz`），213 题逐一标注；
- key 命名格式：`<子主题>-<短词>`（如 `inventor-benz`、`beetle-vw`），语义来自主知识点；
- 映射方式：以各子主题 **beginner 档为主参照系**逐个建 key，starter/intermediate/advanced 按内容归并到已有 key，跨子主题的综合题（大满贯）独立 key；
- 图鉴每主题约 67-68 张卡（以实际标注后为准）。

### 2. 展示：随全局难度动态显示

- 图鉴卡名与 emoji **随当前全局难度档动态显示**（该知识点在当前难度档有题则用该档的 cardName/cardEmoji，无题则回退最近难度，与出题回退同逻辑）；
- **收集状态按 key 稳定**：同一知识点无论难度如何切换只算一张卡；
- 图鉴点卡进扩展页：同样显示当前难度档对应题的扩展内容（回退最近难度）。

### 3. 出题：关内知识点去重

- 普通关 5 题内知识点互不重复（按 knowledge 去重，不足 5 个时降级允许重复）；
- 复习关/宝藏关同理；**家长自定义题不去重**（无 knowledge 字段，视为"附加练习"，不参与知识点收集体系，图鉴不受影响）。

### 4. 存档迁移：自动映射

- 加载时自动迁移：`collectedCardIds`（题目 id）→ `collectedKnowledgeIds`（knowledge key），合并去重；
- 旧字段废弃，一次性迁移终身有效；玩家已收集卡无缝保留。

### 5. 来源 URL 规范（修订 ADR-0013 语义）

- 每题 `sourceUrl` 必须为**专属精确条目**（条目名与扩展知识点强相关，如 AMG 题 → AMG 条目，而非"奔驰"条目）；
- 同一知识点跨难度共享条目可接受；同子主题不同知识点**不得共用** URL；
- 找不到精确条目时：保留文本 `source`，**去掉 `sourceUrl`**（宁缺毋滥，不降级为弱相关链接）；
- 本轮对现有 213 题全量核查修正 + 建立检查清单（域名白名单 + 条目名与知识点对应）作为后续写题硬性规范。

### 6. 关卡树标签（修订 ADR-0012 语义）

- 关卡树"关 1-4 初级、5-8 中级"改为**知识递进语义**（知识基础/知识进阶），与全局难度档解耦；UI 不显示难度档字样。

## 后果

- 优点：图鉴回到"知识单元"语义（一知识一卡），不随难度膨胀；跨难度切换不再产生重复收集；收集状态与存档稳定；扩展页内容与所选难度匹配。
- 代价：213 题逐一标注 knowledge + 全量核查 sourceUrl（内容工作量大）；图鉴/出题/存档三处代码改造；"卡名随难度变化"与收藏品稳定名称的直觉略有出入（已确认接受）。
- 明确不采用：维持题级卡片（图鉴膨胀、重复卡）、按难度分页签（同知识点 4 卡仍重复）、自定义题强制填 knowledge（违背 ADR-0008 家长导入简单性）。
