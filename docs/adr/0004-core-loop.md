# ADR-0004: 核心玩法——答题闯关 + 卡片收集双循环

- 状态：已接受
- 日期：2026-08-03

## 背景

"知识卡片闯关"存在多种玩法形态。目标用户是兴趣驱动型儿童（汽车、历史、我的世界），需要长线动力。

## 决策

采用**双循环**结构：

1. **答题循环**（短循环，单次会话）：进入关卡 → 答 5 题 → 过关得星星（1-3 星）→ 解锁/推进关卡树。
2. **收集循环**（长循环，跨会话）：过关解锁**知识卡片**（每题对应一张卡片）→ 卡片进入**图鉴** → 图鉴收集进度驱动孩子回来继续闯关。

星星是唯一货币：过关得星，用于解锁新关卡与新卡片（见 ADR-0006 的星级规则）。

## 后果

- 优点：收集欲是 7-8 岁孩子的最强动机之一；答题与收集互为燃料，避免纯答题的枯燥。
- 代价：需要卡片图鉴 UI 与解锁动画（见 ADR-0007）；题库需与卡片一一对应（见 ADR-0008）。
- 明确不采用：纯答题闯关（长线动力弱）、卡片即玩法（与答题循环耦合过深）、答题赚方块搭世界（开发量超出 demo 阶段，列为未来方向）。
