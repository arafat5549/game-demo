# ADR-0005: 主题组织与内容方向——三个独立主题世界

- 状态：已接受
- 日期：2026-08-03

## 背景

用户兴趣为汽车、国家历史、我的世界三大主题，三者差异大，需决定组织方式（混合题库 vs 分主题）与各自内容方向。

## 决策

1. **三个独立主题世界**，主界面先选主题再闯关：
   - 🚗 **汽车博物馆**：以德国汽车历史为主线——卡尔·本茨发明第一辆汽车（1886）、奔驰/宝马/奥迪/大众/保时捷的来历与车标故事、甲壳虫、经典车型认脸；
   - 🏯 **历史之旅**：以中国历史为主，人物+故事+文物为锚点（如诸葛亮、李白、四大发明等），不考年代数字，每题附一句话小故事；
   - 🧱 **MC 方块世界**：我的世界游戏知识百科——方块与矿物、生物习性（苦力怕怕什么、如何驯服狼）、生存常识、简单合成；名称用中文俗称，美术用原创像素图（规避 IP，见 ADR-0010）。
2. 每个主题世界拥有：独立的关卡树、独立的卡片图鉴、独立的难度递进。
3. 关卡树结构：普通关 →（每过 3 个普通关）→ 复习关（见 ADR-0006）。

## 后果

- 优点：主题即世界，代入感强；孩子按兴趣自由切换；图鉴可分类收集。
- 代价：题库与美术需按三套风格制作；MC 主题需自绘像素图。
- 风险：历史题必须史实准确（误人子弟风险），题库需人工审核（见 ADR-0008）；"国家历史"范围已确认为中国历史。
