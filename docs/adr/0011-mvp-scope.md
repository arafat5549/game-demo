# ADR-0011: MVP 范围——小而完整，三主题各 2-3 关

- 状态：已接受
- 日期：2026-08-03

## 背景

demo 项目需快速可玩，验证"答题闯关 + 卡片收集"双循环是否成立，同时控制开发周期。

## 决策

MVP 交付范围：

| 模块 | 范围 |
|---|---|
| 主题世界 | 三个主题均开放，各含 2-3 个新手关（普通关）+ 关卡树 | 
| 题库 | 每主题 20 题（初级档为主，覆盖 MVP 关卡）；卡片与题目一一对应 |
| 玩法 | 答题（四选一 + 判断题）、星级结算、星星解锁、过关庆祝 |
| 收集 | 卡片图鉴（部分卡片可解锁）+ 解锁动画 |
| 朗读/音效 | TTS 朗读题目与选项、合成音效与背景乐、一键静音 |
| 错题复习 | 错题池数据结构 + 复习关逻辑（关卡树中第 4 关即首个复习关） |
| 家长专区 | 时长上限 + 休息提醒 + 清除存档 + 静音；家长导入仅交付 JSON 格式文档与导入函数，不做编辑 UI |
| 美术 | 占位风格化图片（AI 生成/色块像素），保证可玩可看 |

明确不做（后续迭代）：家长题导入 UI、成就徽章、排行榜、PWA 离线、云同步、MC 搭世界玩法。

## 后果

- 优点：2-3 天可产出可玩版本；完整覆盖双循环与家长控制，验证价值高。
- 代价：图鉴卡片数量有限，收集长线动力的完整验证需后续扩充题库；美术为占位级，正式视觉需迭代。
