# ADR-0013: 知识扩展——每题图文学习页 + 来源 + 外链

- 状态：已接受
- 日期：2026-08-03
- 关联：ADR-0007（学习时刻）、ADR-0009（家长控制，本 ADR 修订其"零外链"条款）、ADR-0010（素材策略）、ADR-0008（题库策略）

## 背景

现有学习时刻只有一句话 `fact` 朗读。用户要求每道题配备**知识扩展**：图文界面、数据来源和跳转链接，便于孩子深入学习。

## 决策

### 1. 入口（双入口）

- **答题后**：每题答完（答对答错均可），学习时刻/答对反馈出现"📖 了解更多"按钮 → 打开该题扩展页。
- **图鉴**：点击已收集卡片 → 同一扩展页。
- 扩展页不影响答题节奏：答题流程不强制查看。

### 2. 形态：短图文卡片

一页卡片，可滚动，一页装下：
- 大字标题；
- 正文 **2-4 句（50-80 字）**，一键朗读；
- **1 张插图**：MVP 用主题化 emoji + 渐变底，数据模型预留 `image` 字段，后续替换为 AI 生成/免费图库插图（见 ADR-0010 的素材策略，不引入版权风险）；
- 底部**来源 + 链接**区。

### 3. 外链策略（修订 ADR-0009"零外链"条款）

- 外链**直接新窗口打开**（用户决策）。
- 安全护栏：仅允许 **https** 链接；渲染时加 `rel="noopener noreferrer"`；内置题库链接全部人工审核，家长导入题目的链接同样强制 https 校验。
- ADR-0009 的"零广告、零内购、零埋点"保持不变；"零外链"修订为"外链白名单制（https + 人工审核）"。

### 4. 内容规模

- **45 题全配扩展正文**（可复用现有 `fact` 作引言/首句）；
- **约 1/3 配权威链接**，链接策略以**国内可访问**为第一原则：
  - 通用知识（汽车/历史）→ **百度百科**（维基百科国内访问不稳定，2026-08-03 起不再使用）；
  - 游戏知识（MC）→ **我的世界中文 Wiki**（minecraft.fandom.com 国内可访问，百度百科无方块级词条）；
- 每题标注**来源文本**（如"来源：百度百科·卡尔·本茨"）。

### 5. 数据模型与存储格式

题库以 **JSON 格式**存放（`src/data/questions/*.json`，2026-08-03 起内置题库与家长导入题统一为 JSON，落实 ADR-0008 的"题库与代码分离"）：

```ts
interface Expansion {
  title: string          // 大字标题
  body: string           // 2-4 句正文（可朗读）
  image?: string         // 预留：插图 URL/素材 key
  source: string         // 来源文本
  links?: { label: string; url: string }[]  // https 白名单
}
```

## 后果

- 优点：从"知道答案"升级到"理解知识"，教育价值显著提升；来源可溯，历史题可信度可验证；家长导入题也可自带扩展。
- 代价：45 篇正文 + 来源编写是内容成本；外链存在跳转外部站点的固有风险（已用 https + 审核缓解，未来如担心可在家长专区加回"点击需确认"开关）。
- 明确不采用：每题自动展开完整扩展页（打断节奏）、迷你百科长文（2 年级读不完）、互动图集（超 MVP）。
