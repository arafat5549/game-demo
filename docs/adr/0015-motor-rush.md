# ADR-0015: 彩蛋小游戏「摩托大乱斗」——全通解锁的第 4 个小游戏

- 状态：已接受
- 日期：2026-08-03
- 关联：ADR-0014（主题小游戏）、ADR-0003（受众）、ADR-0009（家长控制）

## 背景

用户要求加入类似《暴力摩托》（Road Rash）的竞速对抗小游戏。经多轮访谈确认：**不替换**任何现有小游戏，而是作为**第 4 个小游戏**的彩蛋位；玩法采用**净化版对抗**——保留竞速超车与碰撞的对抗骨架，去除真实暴力表现，适配 2 年级受众与"家长放心"定位。

## 决策

### 1. 定位与解锁

- 小游戏厅新增第 4 张卡「摩托大乱斗」，**不属于任何主题**；
- 解锁条件：**三个主题全部通关**（集齐 3 张主题奖牌 `medal`）；
- 首通送独立图鉴卡 `mg-race`，入**图鉴新增的「🎉 彩蛋」页签**（图鉴入口 3 主题 + 彩蛋共 4 个）；
- 开发模式（`VITE_UNLOCK_MINI_GAMES` 默认）同样默认解锁，便于本地试玩。

### 2. 玩法（净化版对抗竞速）

| 维度 | 决策 |
|---|---|
| 视角 | 后视纵向 3 车道，道路滚动前进 |
| 操作 | 全程点按：点屏幕车道直达切道 + 按住「🏁 加油」加速（巡航 25m/s / 加速 33m/s 量级） |
| 胜负 | 固定里程排名赛（约 3000m）：玩家 + 3 个 AI 对手，先到终点赢；名次定星 1/2/3/4 名 → 3/2/1/1 星，**保底 1 星**（无失败精神） |
| AI | 每 2-4 秒随机变道、速度在基准值 ± 波动；**AI 互不碰撞**，只与玩家交互 |
| 对抗 | 碰撞自动触发：玩家撞 AI → AI 掉 1♥ + 打转减速，玩家自己也略微减速 |
| 体力条 | **仅 AI 有** 3♥ 卡通体力条（表情符号，无血无数字）；归零 = 停下喘息 3 秒后继续，不淘汰不倒地；**玩家无体力条、永不失败** |
| 道具 | 路面随机刷**道具箱**（4 种随机，单槽）：加速（立即）/ 导弹（自动锁定最近对手，-2♥ + 速度减半 3s）/ 减速弹（-0♥，速度减半 4s）/ 碰撞装甲（被动：撞击时对手 -1♥ 且速度归零 2s，自己不掉速）；**捡到全部自动生效**，无主动按钮 |
| 环境 | 路面保留**减速带**：撞上自己减速 1.5s（轮胎冒烟/震动视觉），与道具箱并存 |
| 反馈 | 轻量清晰：碰撞瞬间对手旋转动画 + 😵💫 + 音效 + 屏幕微抖 + 背景滚动减速可见 |
| 时长 | 单局 60-120 秒 |

### 3. 技术实现

- 新组件 `src/ui/minigames/MotorbikeRushGame.tsx`，`requestAnimationFrame` 驱动；车道坐标 + 距离差碰撞检测；emoji 占位素材（ADR-0010）；
- 存档键 `miniGames.race`（`Record<ThemeId, MiniGameProgress>` 扩展为含 `'race'`）；旧存档加载时补默认值（迁移）；
- 元数据 `MINI_GAMES` 增加第 4 项；`MiniGameMeta` 增加 id/解锁条件字段以支持非主题归属；
- `GameResultOverlay` 泛化：race 无主题渐变，结算展示「第 X 名」+ 星级 + 首通彩蛋卡提示；
- 结算/时长：游玩计入每日时长与休息提醒（沿用 ADR-0014 规则）；
- 图鉴彩蛋页签：仅展示 `mg-race` 卡 + 说明文案。

## 后果

- 优点：给全通玩家一个毕业彩蛋（长线目标延长）；不破坏三主题对称结构；净化版对抗保留 Road Rash 的爽感但完全儿童友好。
- 代价：打破 ADR-0014「每主题 1 个小游戏」的对称；图鉴/存档/结算三处需要泛化支持非主题实体；道具系统 + AI + 碰撞的引擎逻辑是本项目第一个连续实时循环（复杂度高于现有三个小游戏）。
- 明确不采用：真实暴力表现（血、武器、倒地淘汰——与 ADR-0003/0009 冲突）、玩家体力条（打破无失败）、多道具槽（低龄误触）、主动发射按钮（全程点按原则）。
