# ADR-0012: 关卡树设计——对称爬塔、子主题分组、奖牌终点

- 状态：已接受
- 日期：2026-08-03
- 关联：ADR-0006（关卡基本规则）、ADR-0004（卡片收集）、ADR-0005（三主题世界）

## 背景

ADR-0006 定了"5 题/关、对 3 过关、错题池 + 定期复习关"，但关卡树的具体形状、命名、解锁门槛、复习关细节、卡片解锁粒度、界面形态与通关奖励均未定。本 ADR 补齐该分支。

## 决策

### 1. 形状：线性主线，三主题对称，各 10 关

- 每主题 **10 关 = 8 普通关 + 2 复习关**，线性无分支，路径清晰。
- **复习关固定在关 4、关 8**（即每过 3 个普通关出现 1 个复习关，与 ADR-0006 一致）。
- **难度映射**：普通关 1-4 为初级档，5-8 为中级档；复习关无难度档。
- 三主题结构完全对称（开发、图鉴、进度预期统一）。

### 2. 命名：每关 = 一个子主题 + 一个童趣关名

- 每关 5 题全部来自该关子主题；每主题 **35 题 = 7 组 × 5 题** 对应关 1-3、5-7、9 共 7 个普通关。
- **关 10"知识大满贯"**：综合混抽关，从本主题全部题目随机抽 5 题（不设专属题组），作为全主题总复习。
- 关名即知识锚点（如汽车主题："发明汽车的爷爷"、"会跑的盒子"），孩子会说"我要玩发明汽车的爷爷那关"。
- 各主题子主题（2026-08-03 已全部配题）：
  - 汽车：发明汽车的人 → 三巨头车标 → 甲壳虫与大众 → 保时捷与跑车 →（复习）→ 宝马与奥迪 → 救援车认脸 → 世界汽车之最 →（复习）→ 未来汽车 → 知识大满贯
  - 历史：远古的中国人 → 秦始皇与长城 → 三国诸葛亮 →（复习）→ 四大发明 → 郑和下西洋 → 古代宝贝 →（复习）→ 节日小故事 → 知识大满贯
  - MC：认识方块 → 挖矿与钻石 → 苦力怕与怪物 →（复习）→ 建造小房子 → 合成工作台 → 红石初探 →（复习）→ 末地与终界 → 知识大满贯

### 3. 解锁门槛：1 星解锁，3 星驱动重玩

- 下一关只需 **1 星** 解锁（答对 3 题即得，永不卡关）。
- 已通关关卡可**随时重玩补星**；全 3 星是奖牌卡的获取条件（见第 6 条）。

### 4. 复习关细节：池空变宝藏关，照常得星

- 错题池有题 → 抽 5 题，答对移出。
- 错题池为空 → 复习关位置变为**宝藏关**（随机抽 5 题，全对额外 +1 星）。
- 复习关/宝藏关照常按 1-3 星结算，关卡树永不被卡住。

### 5. 卡片粒度：每题一卡，逐张翻开

- 保持 ADR-0004 的"题卡一一对应"：过关后该关 5 张卡片**逐张翻开**（约 0.5 秒/张）入册，子主题代表卡最后压轴。
- 每主题图鉴 = **35 张题卡 + 2 张奖牌卡**。

### 6. 终点与通关后：奖牌卡 + 自由挑战

- 爬完 10 关得**主题奖牌卡**（图鉴压轴位）；10 关全 3 星再得**金色奖牌卡**。
- 通关后开放**自由挑战**：随机 5 题、不限次数、照常得星（星星仍可攒，为后续内容预留）。

### 7. 界面：杀戮尖塔式纵向爬塔图

- 参考《杀戮尖塔》爬塔地图：纵向路径（底部起点 → 顶部奖牌终点）、节点连线、**节点类型图标**（普通关=题卡、复习关=🔁、宝藏关=宝箱）、**玩家位置小人**。
- 已通关节点亮色 + 星级徽章，未解锁节点暗色剪影 + 锁，当前关高亮。
- 三主题皮肤：汽车=公路爬坡，历史=古代地图卷轴，MC=方块阶梯。
- MVP 渲染完整 10 节点，仅前 2-3 关可玩，其余暗锁（见 ADR-0011）。

## 后果

- 题库编写按"8 子主题 × 5 题 × 2 难度档"组织，子主题清单先行定稿。
- 每主题需 42 张卡片图（40 题卡 + 2 奖牌卡），题卡图与四选一配图尽量复用（见 ADR-0008、ADR-0010）。
- 爬塔图为三主题共用组件，皮肤由主题配置驱动。
- 明确不采用：分支路径（题库量翻倍、低龄困惑）、2 星解锁（可能卡关）、通关即毕业（无长线可玩）、二周目（超 MVP 范围，列为未来方向）。
