# ADR-0016: 难度系统——4 档年级制，进入游戏时全局选择

- 状态：已接受
- 日期：2026-08-03
- 关联：ADR-0003（受众定位，本 ADR 将其从"2 年级专用"扩展为多年龄段）、ADR-0008（题库策略）、ADR-0006（关卡难度）

## 背景

用户要求"题库难度可选、不限定二年级、按照难度系统来"。原设计面向 2 年级（ADR-0003），难度仅两档（beginner/intermediate）。

## 决策

### 1. 难度体系：4 档年级制

| 档位 | 枚举 | 目标年龄 | 说明 |
|---|---|---|---|
| 🌱 启蒙 | `starter` | 幼儿园大班~1 年级 | 最直白表述、大字短句 |
| ⭐ 初级 | `beginner` | 2 年级 | 现有 105 题归此档 |
| 🚀 中级 | `intermediate` | 3-4 年级 | 现有原 `intermediate` 标记题归此档 |
| 👑 高级 | `advanced` | 5-6 年级 | 后续分批补充 |

### 1b. 题目档位划分标准（三维定性，2026-08-03 确认）

一道题属于哪个档位，按以下三个维度综合判定：

1. **表述复杂度**：词句长短、是否口语化、是否使用低龄熟词（启蒙档短句直白，高级档可含年代/术语）；
2. **选项复杂度**：判断题（启蒙/初级）→ 四选一（中级）→ 细节辨析、需排除干扰项（高级）；
3. **知识深度**：记忆（认得名字）→ 理解（知道特征/关系）→ 应用（年代、因果、跨知识点关联）。

同一知识点可跨档出现多题，但内容深度必须递进（如启蒙"认识奔驰"、初级"汽车之父"、高级"奔驰与戴姆勒合并史"）。

### 2. 难度选择：进入游戏时全局选择

- 主界面显著位置放**难度选择器**（4 档大按钮，附年龄说明）；
- 选择存入设置（`settings.difficulty`，默认 `beginner`），**全局生效**：三个主题世界都按所选难度出题；
- 孩子/家长随时可切换（存档进度不受影响，星级/图鉴按主题独立）；
- 关卡树结构、题量、星级规则不变（ADR-0012）。

### 3. 出题规则：按难度出题 + 最近难度回退

- 普通关：从该子主题题目中，按**难度距离最近优先**抽 5 题（同难度随机，同距离随机）；
- 选中难度没有题时自动回退到相邻难度（如 `starter` 无题 → `beginner`；`advanced` 无题 → `intermediate`），保证任何档位都可玩；
- 复习关/宝藏关/大满贯同理按所选难度优先；
- 家长自定义题同样参与难度匹配。

### 4. 内容策略：分期填充

- 本次：现有 105 题重标（`beginner`→初级、`intermediate`→中级）+ 新增启蒙档每主题 7 题（共 21 题，够开一关）；
- 后续：中级/高级逐步补到每主题 35 题（每主题 140 题全配齐为目标）。
- **存储格式**（2026-08-03）：题库按难度分文件夹存放 `src/data/questions/<难度>/<主题>.json`（`starter`/`beginner`/`intermediate`/`advanced`），便于分档维护与审核；当前每主题 71 题（启蒙 8-9 / 初级 21-23 / 中级 26-28 / 高级 14），每档覆盖全部 7 子主题。

## 后果

- 优点：覆盖幼儿园~小学全段，产品不再受"2 年级"定位限制；难度选择直观；旧存档无缝兼容（默认初级）。
- 代价：内容总量目标变为每主题 140 题，写作量大需分批；同一子主题需维护多难度版本题（难度梯度设计需注意：同知识点、不同表述/深度）。
- 明确不采用：每主题独立难度设置（管理复杂）、难度与关卡树分支绑定（破坏 10 关结构）、无回退的严格难度（空档期不可玩）。
