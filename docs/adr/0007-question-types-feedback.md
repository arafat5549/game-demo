# ADR-0007: 题型与反馈——图片四选一为主 + 全量正反馈

- 状态：已接受
- 日期：2026-08-03

## 背景

题型受限于低龄孩子的操作能力（点按最稳，拖拽易误触）；反馈设计决定学习效果与情绪体验。

## 决策

1. **题型**：以**图片四选一**为主（大图 + 大字，点一下即答），辅以少量**判断题**（对/错两个大按钮）。不采用拖拽配对。
2. **答对反馈**：彩带动画 + 欢快合成音效 + 星星飞入；**连续答对 3 题**触发连击特效。
3. **答错反馈（学习时刻）**：温和提示"再想想"，随后展示正确答案卡片并朗读，不嘲笑、不扣分、不惩罚；该题进入错题池（见 ADR-0006）。
4. **过关庆祝**：星级结算页 + 新知识卡片解锁动画 + 图鉴翻开（呼应 ADR-0004 的收集循环）。

## 后果

- 优点：全程点按零门槛；错误即学习机会，孩子不怕答错；收集解锁动画强化长循环动机。
- 代价：需要彩带/连击/解锁三类动画（Framer Motion 实现，见 ADR-0002）；每题需配图（见 ADR-0010 的素材策略）。
- 明确不采用：排行榜/成就徽章（竞争焦虑，超出 demo 范围，列为未来方向）。
