# ADR-0010: 视觉与音频素材策略——原创、零版权风险

- 状态：已接受
- 日期：2026-08-03

## 背景

视觉对儿童是第一吸引力；音频需覆盖音效与朗读；"我的世界"是微软 IP，直接使用官方素材有侵权风险。

## 决策

1. **视觉风格**：整体明亮卡通风；汽车/历史主题用扁平插画风；MC 主题用**原创像素图**（自绘，不复制官方素材，方块造型不与官方纹理一致）。图片来源：AI 生成 + 人工筛选修整，或免费图库；MC 主题一律自绘。
2. **音效与背景音乐**：Web Audio API 合成（零素材、零授权成本）；背景音乐为合成轻快旋律，可一键静音。
3. **朗读**：浏览器内置 SpeechSynthesis API（TTS）朗读题目/选项/知识小故事，中文语音，零资源体积。
4. **命名规避**：MC 主题题目使用中文俗称（如"苦力怕"）与通用描述，不使用官方专有商标名做标题性呈现。

## 后果

- 优点：全部素材可商用、可随仓库分发；TTS 免去录音与配音资源；加载体积小。
- 代价：合成音效与 TTS 音质不如真人配音（demo 阶段可接受）；MC 像素图需要美术工作量，MVP 阶段先用简单色块像素图（见 ADR-0011）。
- 风险：不同浏览器/设备的 TTS 中文语音质量有差异，需在 MVP 实测降级方案（无 TTS 时静默降级，不影响答题）。
