# 词汇表（Glossary）

本项目内部使用的统一术语，所有文档、代码、UI 文案保持一致。

| 术语 | 英文标识 | 定义 |
|---|---|---|
| 主题世界 | `themeWorld` | 三大兴趣主题之一：汽车博物馆 / 历史之旅 / MC 方块世界；拥有独立关卡树与图鉴 |
| 关卡 | `level` | 一次 5 题的闯关单元，答对 3 题过关，得 1-3 星 |
| 关卡树 | `levelTree` | 每主题 10 关的线性结构（8 普通 + 2 复习），杀戮尖塔式爬塔图呈现 |
| 子主题 | `subTheme` | 每个普通关的专属知识分组，5 题全部来自该组；40 题 = 8 组 |
| 普通关 | `normalLevel` | 常规出题的关卡，按主题关卡树推进；关 1-4 知识基础、5-8 知识进阶（知识递进语义，与难度档解耦，见 ADR-0017） |
| 复习关 | `reviewLevel` | 从错题池抽 5 题的关卡，固定在第 4、第 8 位 |
| 宝藏关 | `treasureLevel` | 错题池为空时替代复习关：随机 5 题，全对额外 +1 星 |
| 爬塔图 | `climbMap` | 纵向关卡地图：节点连线、类型图标、玩家小人、亮星/暗锁 |
| 奖牌卡 | `medalCard` | 爬完 10 关获得的图鉴压轴卡片 |
| 金色奖牌卡 | `goldMedalCard` | 10 关全 3 星额外获得的卡片 |
| 自由挑战 | `freeChallenge` | 通关后开放的随机 5 题模式，不限次数、照常得星 |
| 小游戏厅 | `miniGameHall` | 主界面的小游戏选型界面：每主题 1 个小游戏，主题通关后解锁（ADR-0014） |
| 小游戏卡 | `miniGameCard` | 小游戏首通奖励卡（每主题 1 张），入图鉴（ADR-0014） |
| 彩蛋小游戏 | `bonusMiniGame` | 第 4 个小游戏「摩托大乱斗」：三主题全部通关后解锁，不属于任何主题（ADR-0015） |
| 摩托大乱斗 | `motorRush` | 净化版对抗竞速：后视 3 车道、点道切车、按住加速、碰撞减速对手，名次定星（ADR-0015） |
| 体力条 | `healthBar` | 仅 AI 对手拥有的卡通 3♥ 体力条：导弹 -2、装甲撞击 -1，归零停下喘息 3 秒后继续；玩家无体力条、永不失败（ADR-0015） |
| 道具箱 | `powerUpBox` | 路面随机刷新的道具：加速 / 导弹 / 减速弹 / 碰撞装甲，捡到自动生效（ADR-0015） |
| 减速带 | `slowStrip` | 路面上使玩家短暂减速的障碍，撞上减速 1.5 秒（ADR-0015） |
| 错题池 | `mistakePool` | 答错题目的集合；复习关答对后移出 |
| 知识卡片 | `card` | 与知识点对应的收集物（ADR-0017），同知识点跨难度共享一张卡，过关后解锁，收入图鉴 |
| 知识点 key | `knowledge` | 知识点的稳定标识（如 `inventor-benz`），格式 `<子主题>-<短词>`；题库每题一个，同知识点跨难度共用（ADR-0017） |
| 图鉴 | `collection` | 已解锁卡片的收集册，按主题分类；卡名随全局难度动态显示，收集状态按知识点 key 稳定 |
| 星星 | `stars` | 过关奖励货币（全对 3 星 / 对 4 题 2 星 / 对 3 题 1 星），用于解锁关卡与卡片 |
| 学习时刻 | `learningMoment` | 答错后的反馈环节：温和提示 + 展示并朗读正确答案 |
| 连击 | `combo` | 连续答对 3 题触发的特效奖励 |
| 家长专区 | `parentZone` | 谜题解锁的家长设置区：时长上限、休息提醒、导入题目、静音、清除存档 |
| 每日时长上限 | `dailyTimeLimit` | 家长设置的每日游玩上限，到点锁定，次日重置 |
| 休息提醒 | `breakReminder` | 每 15 分钟提醒护眼休息 |
| 本地存档 | `localSave` | localStorage 中的进度数据：星星、关卡进度、图鉴、错题池、家长设置 |
| 内置题库 | `builtinBank` | 随游戏分发的人工审核题库（每主题 71 题：启蒙 8 / 初级 22 / 中级 27 / 高级 14），按难度分文件夹存放（ADR-0016） |
| 家长自定义题 | `customBank` | 家长通过 JSON 导入的题目，独立于内置题库；无知识点 key，不参与知识点去重与图鉴收集 |
| 知识扩展 | `expansion` | 每道题配的图文学习页：标题 + 2-4 句正文 + 插图 + 来源 + 外链（ADR-0013） |
| 来源 | `source` | 扩展内容的资料来源文本（如"维基百科·卡尔·本茨"），保证史实可溯 |
| 来源链接 | `sourceUrl` | 扩展内容的专属精确条目链接（百度百科 item / MC Fandom wiki），条目名必须与知识点强相关；找不到精确条目时省略该字段（宁缺毋滥，ADR-0017） |
| 外链 | `links` | 扩展页跳转链接，https 白名单制 + 人工审核，新窗口打开 |
| TTS | — | 浏览器 SpeechSynthesis 中文语音朗读 |
| 难度档 | `difficulty` | 4 档年级制（ADR-0016）：🌱启蒙 / ⭐初级 / 🚀中级 / 👑高级；主界面全局选择，出题按难度最近回退 |
| MVP | — | 首个可玩版本：三主题各 2-3 关 + 核心双循环 + 家长专区（见 ADR-0011） |
