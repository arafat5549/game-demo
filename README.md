# game-demo — 知识卡片闯关游戏

给 2 年级小朋友的知识卡片闯关游戏。兴趣驱动：🚗 汽车（德国汽车历史）· 🏯 中国历史 · 🧱 我的世界。

答题闯关赢星星 → 星星解锁知识卡片 → 卡片填满三大兴趣世界的图鉴。

## 快速开始

```bash
npm install
npm run dev      # 开发：http://localhost:5173（小游戏厅默认全部解锁，免通关试玩）
npm run build    # 构建：产物在 dist/，可部署到 GitHub Pages / Vercel
```

> 本地开发默认解锁全部小游戏（`import.meta.env.DEV`）。想恢复"通关解锁"逻辑：
> 在项目根目录建 `.env` 文件，写入 `VITE_UNLOCK_MINI_GAMES=false` 后重启 `npm run dev`。
> 生产构建（`npm run build`）始终按正常规则（通关解锁），不受影响。

## 安装到手机（PWA）

游戏已支持 PWA：可以像 App 一样装到手机/平板主屏幕，**离线也能玩**。

### 🎮 线上地址（已部署，直接打开玩）

**https://arafat5549.github.io/game-demo/**

用手机浏览器打开这个地址，即可按下面的步骤安装到主屏幕。

### 安装步骤

- **Android（Chrome/Edge）**：用浏览器打开游戏网址 → 菜单 ⋮ →「安装应用」或「添加到主屏幕」→ 桌面出现图标，全屏打开
- **iPhone/iPad（Safari）**：打开网址 → 底部分享按钮 ⬆️ →「添加到主屏幕」→ 点「添加」
- 安装后断网也能玩；进度存在设备本地

### 重新部署（更新内容后）

```bash
npm run build
git add -A && git commit -m "更新" && git push
```

推送到 `main` 分支后，GitHub Actions 会自动构建并部署（约 1 分钟生效）。

### 局域网快速测试（不安装、无离线）

```bash
npm run preview -- --host 0.0.0.0
```

手机连同一 WiFi，浏览器访问 `http://电脑IP:4173` 即可玩（http 下无法"安装"，但功能完整）。

## 当前进度（MVP 第一版已可玩）

- ✅ 三个主题世界：汽车博物馆 / 历史之旅 / MC 方块世界
- ✅ 杀戮尖塔式爬塔关卡图（10 节点全通：7 个普通关 + 2 复习关 + 大满贯综合关）
- ✅ 答题闯关：5 题/关、答对 3 题过关、1-3 星、连击特效
- ✅ 学习时刻：答错展示知识小故事并朗读
- ✅ 知识扩展：每题图文学习页（45 题全配）+ 来源标注 + 15 个 https 白名单外链（百度百科为主，国内可访问）
- ✅ 题库 JSON 化：内置题库全部为 JSON 格式，与代码分离，可直接编辑或对照家长导入格式
- ✅ 错题池 + 复习关（第 4、8 位；池空变宝藏关，全对 +1 星）
- ✅ 卡片收集：过关逐张翻开、图鉴、奖牌卡
- ✅ 内置题库 168 题（每主题 56 题，4 档难度，每子主题多难度覆盖，切难度真实换题）
- ✅ 难度系统：主界面全局选择（选中高亮 ✓ + 切换播报 + 确认提示），答题页显示全局难度与题难度徽章、回退提示
- ✅ TTS 朗读题目 + Web Audio 合成音效 + 一键静音
- ✅ 家长专区：星星谜题解锁、每日时长上限、清除存档
- ✅ 家长自定义题：JSON 导入（文件/粘贴）、校验、题目列表管理；自定义题进入宝藏关与复习关
- ✅ PWA：可安装到主屏幕、离线可玩（manifest + Service Worker + 图标）
- ✅ 小游戏厅：🚗 汽车组装 / 🏯 文物拼图 / 🧱 挖矿大作战（主题通关解锁，首通送小游戏卡）
- ⏳ 待办：扩展页插图升级

## 技术栈

Vite + React 19 + TypeScript + TailwindCSS v4 + Framer Motion，纯静态，存档在 localStorage。
